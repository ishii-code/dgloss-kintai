# 固定残業超過アラート（Google チャット通知）

指定した事業部（既定: **パートナー事業部 / AIテレアポ事業部**）の一般従業員について、
**当月の残業が固定残業枠を超えて追加の残業代（差額支給）が発生する見込み**になったら、
Google チャットに通知します。

- 判定: 当月1日〜基準日（既定は実行日）の日次勤怠を月次締めと同じ計算で集計し、
  固定時間外勤務手当を超えた差額支給（`fixedOvertimeAdditionalPayment`）が 0 円超になったら超過。
- 対象: 指定事業部 × 非管理監督者 × 固定残業手当あり（> 0）。
- 重複防止: 従業員×年月で**初めて超過した1回だけ**通知（`OvertimeAlert` テーブルで冪等）。
- 起動: Vercel Cron で**毎日**実行（既定 10:00 UTC = 19:00 JST）。管理者は手動実行も可。

## セットアップ手順

### 1) DB マイグレーション（必須）

Neon の SQL Editor / Vercel の Query に `deploy/add-overtime-alerts.sql` を貼って実行します
（事業部列 `Employee.department` と `OvertimeAlert` テーブルを追加・冪等）。

> ⚠️ このテーブルが無いと、重複通知を避けるため通知は**送信されません**（安全側で休止）。

### 2) 事業部（department）を従業員に取り込む

通知は「事業部」で絞り込みます。jinjer から書き出す CSV に `事業部` 列が追加されています
（`packages/kintai-connector-jinjer/scripts/export-jinjer-full-csv.mjs` が jinjer の部署名を自動設定）。
その CSV をアプリの「インポート」画面から取り込むと、各従業員に事業部が入ります。

### 3) Google チャットの受信ウェブフックを作る

1. 通知を送りたい Google チャットの**スペース**を開く
2. スペース名 → 「アプリと連携」→「ウェブフック」→「ウェブフックを追加」
3. 名前（例: 勤怠アラート）を付けて作成し、表示された **Webhook URL をコピー**

> この URL はトークンを含む秘密情報です。チャットや共有の場に貼らないでください。

### 4) 環境変数（Vercel）

| 変数名 | 必須 | 説明 |
|---|---|---|
| `GOOGLE_CHAT_WEBHOOK_URL` | ○ | 手順3の Webhook URL。未設定だと送信せずログのみ（休止）。 |
| `CRON_SECRET` | 推奨 | Vercel Cron 認可用。設定すると Cron 以外からの自動実行を拒否。 |
| `KINTAI_OVERTIME_ALERT_DEPARTMENTS` | 任意 | 対象事業部をカンマ区切りで上書き（既定: `パートナー事業部,AIテレアポ事業部`）。 |

設定後に再デプロイすると、`vercel.json` の `crons` に従って毎日自動実行されます。

## 手動実行・動作確認

管理者でログインした状態で、次を叩くと即時実行できます（基準日・年月は任意指定可）。

```
GET /api/cron/overtime-alerts
GET /api/cron/overtime-alerts?year=2026&month=10&asOf=2026-10-20
```

レスポンス例:

```json
{ "result": { "period": { "year": 2026, "month": 10 }, "asOf": "2026-10-07",
  "checkedCount": 120, "triggeredCount": 3, "alreadyNotifiedCount": 1, "alerts": [ ... ] } }
```

## 補足・設計メモ

- 「固定残業超過」は**月の残業合計 vs 固定残業枠**の月単位判定のため、月途中は「当月見込み」です
  （基準日までの累計。残業が増えるほど枠に近づき、超えたら通知）。
- 本判定は保存済みの日次勤怠（WorkDay）を参照します。打刻の日次化（勤怠ビルド）を日々行っている
  前提です。未ビルドの当日分は見込みに含まれません。
- 所得税・社会保険料は対象外（本システムのスコープ外）。あくまで総支給側の時間外差額の話です。
