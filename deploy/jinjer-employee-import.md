# jinjer 従業員データの取り込み手順

jinjer から**全従業員の実データ**を本システムへ入れる手順です。API キー／シークレットは不要で、
CSV 取り込み（画面の「インポート」）だけで完結します。

> なぜ CSV か: 本システムは jinjer API に直接接続していません（API 仕様が未確定で、認証情報を
> 扱わない方針のため）。jinjer の従業員マスタ**エクスポート → CSV 取込**が確実・安全な方法です。

## 手順

1. **jinjer でエクスポート**: jinjer 管理画面の従業員一覧から、従業員マスタを CSV／Excel で出力する。
2. **本システムの列に合わせる**: 出力を下表の 16 列に並べ替える（`deploy/employee-import-template.csv`
   をひな形に、値を貼り替えるのが簡単）。
3. **取り込む**: 本システムの「インポート」画面（`/import`・管理者）で CSV を貼り付け／アップロードする。
   - キーは**社員番号**。既存の社員番号は上書き、無ければ新規作成（何度実行してもよい）。

## 列の対応（本システム 16 列）

| 列 | 必須 | 値の例・区分 |
| --- | --- | --- |
| 社員番号 | ○ | 一意キー。例 `0001` |
| 氏名 | ○ | 例 `山田 太郎` |
| メール | | 空可 |
| 入社日 | ○ | `YYYY-MM-DD` |
| 退職日 | | 在籍中は空 |
| 雇用区分 | ○ | `正社員` / `非正規` |
| 勤務体系 | ○ | `固定時間制` / `フレックスタイム制` / `シフト制` / `裁量労働制` |
| 所属 | ○ | `本社` / `法人営業` / `個人営業` |
| 管理監督者 | ○ | `はい` / `いいえ`（労基法第41条2号該当） |
| 基本給 | ○ | 月額・円。例 `300000` |
| 年間所定労働時間 | ○ | 時間。例 `1900` |
| 固定残業手当 | ○ | 円。無ければ `0` |
| 充当_時間外 | ○ | `はい` / `いいえ`（固定残業手当の充当対象） |
| 充当_60時間超 | ○ | `はい` / `いいえ` |
| 充当_休日 | ○ | `はい` / `いいえ` |
| 充当_深夜 | ○ | `はい` / `いいえ` |

- 文字コードは UTF-8。Excel で開く場合は BOM 付き（ひな形は BOM 付きにしてあります）。
- `所属` が本システムの 3 区分に無い場合は、最も近い区分へ寄せてください（区分は今後拡張可能）。
- 固定残業がない従業員は `固定残業手当=0`・`充当_*=いいえ` にします。

## 補足

- 勤怠・打刻・締めの実データは従業員取込後に、打刻または別途の取込で積み上げます
  （本手順は**従業員マスタ**の取り込みです）。
- もし jinjer のエクスポート CSV をそのまま渡していただければ、本システムの 16 列へ変換した
  取込用 CSV をこちらで作成することもできます（認証情報は不要・従業員情報のみ）。
